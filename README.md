# Color Tracking Using Python and OpenCV

## About the Project
This project uses Python and OpenCV to detect and track objects of a specific color in real time using a webcam.

## Features
- Real-time color detection
- Webcam-based object tracking
- HSV color segmentation
- Visual tracking of selected colors

## Technologies Used
- Python
- OpenCV
- NumPy

## Requirements
Install the required libraries:

```bash
pip install opencv-python numpy
```

## How to Run
1. Clone or download this repository.
2. Install the required libraries.
3. Run the Python script:

```bash
python color_tracking.py
```

Replace `color_tracking.py` with the actual name of your Python file if it is different.
